# DynamicIsland‑Launcher
Current Version: v1.0.0

![Version settings screenshot](./Media/Version%20settings.png)

[Preview Demo Video](./Media/preview.mp4)

## Overview
A WPF‑based desktop launcher with iOS‑style DynamicIsland overlay feature.
Only Chinese language is supported at this moment, continuously updated.

## Features
- iOS‑style DynamicIsland floating overlay
- Localized Chinese UI
- Minecraft version download & management
- Launch configuration management
- Download progress display

## Requirements
- Windows 10 / Windows 11
- .NET 8 Desktop Runtime

## Build from source
1. Clone this repository
2. Open `DynamicIsland.csproj` with Visual Studio 2022
3. Restore nuget packages
4. Build and run
